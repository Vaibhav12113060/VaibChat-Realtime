# 💬 Chat-Application (MERN Stack)

A **full-stack Chat Application** planned using the **MERN stack**.  
The project is currently **in progress**, with the **backend fully implemented** and the **frontend under development**.

This application is designed to support secure and scalable real-time communication.

🚧 **Project Status:** Backend completed | Frontend in progress

---

## 🚀 Current Features (Backend)

- User authentication & authorization (JWT-based)
- Secure user registration and login
- RESTful API design for chat functionality
- MongoDB schema design using Mongoose
- Protected routes for authenticated users
- Centralized error handling
- Modular and scalable backend architecture

---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript (ES6+)
- JWT Authentication

### Frontend (Planned)
- React.js
- Hooks / Context API
- Responsive chat UI
- Real-time message handling

---

## 🔐 Authentication
- JWT-based authentication
- Password hashing
- Secure protected routes

---

## 🧠 Project Summary
**Chat-Application** is being built as a production-ready MERN project.  
The backend focuses on secure authentication, clean API design, and scalable data modeling. The frontend will handle user interaction, messaging UI, and real-time updates.

The application will later be enhanced with WebSocket-based real-time communication.
